# 验证记录

## 0.2.1 · 2026-10-23

目标环境仍为 Windows、DSH Desktop 0.2.1-rc.2、Edge。

- 20 项本地功能测试通过。新增覆盖真实鼠标按下—移动—抬起、原生 range 滑块、拖动控件和 HTML5 拖放；过期指针松手不会影响新的手势。
- 已验证取消、交还 AI 和失联超时会松键；取消按下不会意外触发按钮点击。
- 已验证文本框、文本区、方向键和 iframe 中的插入光标坐标，反馈不返回输入值。
- 已验证移动事件合并后仍保持 down/move/up 顺序，失败后发送取消。
- 已验证 DSH 分栏标记在失焦、取消、失去捕获、漏掉松手后恢复；正常 pointerup 先提交布局，不被兼容清理误取消。
- `test/client.integration.mjs` 使用实际 `client.js`、React 18.2、真实 HTTP 接口和两个 Edge 浏览器上下文联测，侧栏原生鼠标拖动、文字输入、方向键光标、失焦松键、后续点击和分栏标记恢复全部通过。
- 在宽 640 和窄 420 像素的侧栏布局中检查了竖直插入光标和缩放后的坐标。

指针正常操作由 Edge 的原生鼠标输入驱动；窗口失焦、丢失捕获和漏掉松手的恢复使用合成事件。未把物理鼠标移出实际 Windows 窗口或真实验证码挑战计入自动化测试。站点仍可有独立的交互与风控限制，插件不自动解验证码。

## 0.2.0 · 2026-10-22

- 从普通宿主进程执行独立安装器，使用 DSH 自带的 `dsh plugin` 管理命令。

- `dsh-web-workbench` 0.2.0 已加入 desktop profile；保留已有插件和选择。
- 默认安装压缩包；已核对安装文件与源码一致、依赖齐全、压缩包引用存在。旧开发链接升级前只解除经过路径检查的链接本身，避免 pnpm 清理跟随 Windows junction 进入源码。
- 没有启用全盘写权限、修改账户凭证或中断正在运行的 DSH 任务。

- 16 项本地功能测试通过：同一浏览器的 AI/人工切换、坐标点击、键盘与中文输入、接管时拦截排队的 AI 操作、侧栏上传下载、超限上传清理、会话文件隔离、二进制下载、重定向、流式限制、取消清理、PDF 文字提取、渲染、扫描 PDF OCR、浏览器交互、弹窗、标签页、登录恢复、中英文 OCR、视频元信息和取帧。
- 使用 DSH 自带原生校验器检查参数和输出 Schema。

这些结果不保证所有外部网站都允许自动化，也不表示已经在真实站点发送邮件、发帖或下单。测试未使用真实账号，未绕过 CAPTCHA、MFA 或付费权限。桌面整窗截图在本机自动化环境中超时；侧栏画面通过客户端诊断、实际图片元素和同一浏览器的截图核对。
